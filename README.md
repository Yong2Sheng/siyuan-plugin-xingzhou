# 行舟 · 个人项目与事务中心

行舟是一个面向个人时间的思源笔记插件。它把原生属性视图保留为唯一数据源，在其上提供更适合浏览、选择和逐步展开项目的界面。

> 当前版本：`0.1.1`（安全删除更新）

[English README](README.en.md) · [中文更新日志](CHANGELOG.md) · [English Changelog](CHANGELOG.en.md)

## 设计目标

- 降低“有私人时间时，我该做什么”的决策成本；
- 用同一个数据库捕获长期领域、项目、任务、事务和想法；
- 项目主页保存完整地图，数据库只管理当前需要被看见的工作项；
- 只记录直接上层关系，并据此恢复完整层级；
- 简单的一次性事务留在数据库，不强迫建立文档；
- 让界面跟随思源主题与深色模式；
- 不把个人项目管理变成新的绩效压力。

## 当前开发进度

- 从指定的思源属性视图读取“全部工作项”；
- “长期领域”和“独立工作项”入口；
- 默认仅展开活跃路径，也可以全部收起；
- “全部 / 活跃项目 / 将来 / 已结束”筛选；
- 详情页展示并直接编辑层级、类型、状态、计划日期、截止日期、预计时长与所需精力；
- 名称与完成按钮位于同一行，完成后按钮消失，状态仍是唯一进度依据；
- 点击“本次行动细则”或“下一步行动”卡片即可原地编辑；失焦自动保存，`Esc` 取消，`Cmd/Ctrl + Enter` 保存；
- 以“本次行动细则”为主要内容，以“下一步行动”为辅助内容；
- 设置计划日期时将“收件箱／待开始”调整为“已计划”，但不根据日期自动伪装成“进行中”；
- 根据本地日期动态显示“今日”和“已逾期”，不回写生命周期状态；
- “本周”按实际日期显示周一至周日，支持上一周、本周和下一周导航；
- “待安排”只收纳尚未选择日期的事务与想法，并单独提醒当前处于计划日期—截止日期窗口内的执行项；
- 可在周视图中安排、移动、取消安排或完成事项；
- “整理”提供收件箱、活跃顶层项目、遗留日期、行动细则和本周结果五步检查；
- 周度整理使用单项优先级，同一条目每轮只出现在一个最先需要处理的步骤中；
- 打开已关联的思源文档，或跳回原生数据库；
- 检查自指、多个直接上层、缺失父项、循环和顶层项目不一致；
- 在列表、树、卡片和详情标题区右键打开工作项菜单，经二次确认后从属性视图删除目标条目；
- 加载、空数据、接口错误和缺失可选字段的状态提示；
- 适配思源主题变量和深色模式；
- 设置属性视图 ID 与数据库块 ID。

当前版本会在用户明确操作时新增收件箱独立行，保存详情、本周安排与完成状态，或删除目标属性视图条目；不会新增或删除数据库字段，不会自动创建文档，也不会自动修复关系。删除前会再次确认：关联文档只解除数据库绑定，不会随条目删除；下级工作项不会级联删除，仍有关系引用时会明确提醒。

发布前按方案报告逐项审计，首版核心需求覆盖度约为 **94%**。尚未实现的内容主要是折叠状态和默认页面持久化、拖放排期、并发冲突提示、原生数据库行精确定位、自动创建文档与层级图挂件，不影响“捕获—整理—安排—执行—回顾”的主流程。

## 数据库约定

行舟会按字段名称识别数据，当前约定如下：

| 字段 | 用途 | v0.1 |
| --- | --- | --- |
| 工作项 | 名称和关联块 | 必需 |
| 工作项类型 | 长期领域、项目、任务、事务、想法 | 建议 |
| 状态 | 收件箱、待开始、已计划、进行中、阻塞、暂停、将来、已完成、已失败、已取消、已放弃 | 建议；旧状态暂时兼容读取 |
| 上层工作项 | 只指向直接上一级 | 建议 |
| 所属顶层项目 | 快速定位顶层项目 | 可选 |
| 本次行动细则 | 当前工作项要做的内容，详情页视觉主位 | 可选；缺失时兼容 |
| 下一步行动 | 明确存在前后关系时，记录随后要做的动作 | 可选 |
| 计划日期 | 安排到实际日期 | 可选 |
| 截止日期 | 只在存在真实期限时填写 | 可选 |
| 预计时长（分钟） | 当前可执行工作所需时间 | 可选 |
| 所需精力 | 低、中、高 | 可选 |

数据库应保存顶层项目、当前子项目和当前需要管理的可执行任务，不必复制项目主页里的全部拆分结果。

## 安装测试包

1. 下载发布附件中的 `package.zip`。
2. 在思源工作空间的 `data/plugins/` 下创建 `siyuan-plugin-xingzhou` 文件夹。
3. 将压缩包内容解压到该文件夹，确保 `plugin.json` 位于文件夹根部。
4. 重启思源或重新加载插件，然后在集市已下载插件中启用“行舟”。
5. 打开插件设置，确认属性视图 ID 和数据库块 ID。

## 本地开发

```bash
pnpm install
pnpm test
pnpm check
pnpm build
```

`pnpm build` 会生成 `dist/` 和可安装的 `package.zip`。

## 数据与隐私

- 行舟不包含远程服务；
- 插件只通过思源本地 API 访问配置的属性视图，并仅在用户快速捕获、编辑详情、安排日期、明确完成或二次确认删除时修改目标数据；
- 插件私有数据只保存两个绑定 ID；
- 插件不会访问其他工作空间，也不会扫描未配置的笔记本；
- `disabledInPublish` 已启用，避免在发布服务中加载个人管理界面。

## 数据库结构提示

插件不会擅自改造数据库结构。首次使用前，请确认目标属性视图已包含上表中需要使用的字段，尤其是“本次行动细则”文本字段；旧状态仍可读取，但建议逐步改用当前状态集合，并同步检查原生视图的筛选条件。
